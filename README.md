# Módulo 4 · Unidade 1 — Agentes Autônomos e Raciocínio Encadeado

Página didática interativa de apoio aos alunos do **Curso de Formação em IA Generativa**.

## Sobre esta Unidade
Esta unidade aborda a transição de sistemas que apenas respondem perguntas para **Agentes Autônomos** capazes de receber um objetivo, planejar etapas, utilizar ferramentas e avaliar resultados em ciclos contínuos (*Perceber → Planejar → Agir → Avaliar*).

### Recursos da Aplicação
- **Simulador Visual Dinâmico**: Acompanhamento animado do ciclo do agente.
- **Conteúdo Interativo**: Tópicos com explicações *Do Zero*, *Na Prática*, *Atenção / Risco* e *Ponto-chave*.
- **Quiz de Fixação**: 10 perguntas com feedback imediato e explicação.
- **Jogo da Memória**: Combinação de conceitos e definições da unidade.

## Stack Tecnológica
- **Next.js** (App Router com `output: "export"` para deploy estático)
- **Tailwind CSS**
- **Lucide React**

## Como executar localmente
```bash
npm install
npm run dev
```

## Publicação na Vercel
Importe o repositório no GitHub, selecione o diretório `MOD4/U1-WEB` como **Root Directory** e faça o deploy (sem necessidade de banco de dados ou variáveis de ambiente).
